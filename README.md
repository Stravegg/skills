# `@strave/skills`

Official Agent Skills for building Rainbow Six Siege applications on Strave, formatted for [skills.sh](https://skills.sh).

## Install with `skills.sh`

```bash
npx skills add Stravegg/skills
```

## Included skills

- `strave-auth` — Login with Strave (`@strave/auth`) and zero-secret OIDC Trusted Workloads.
- `strave-sdk` — `@strave/sdk` for plain TypeScript and Effect v4, Sandbox mode, pagination, and SSE streams.
- `strave-replay-embed` — OIDC-authenticated 2D replay viewer sessions and `@strave/replay-embed`.
- `strave-webhooks` — Web Crypto HMAC-SHA256 webhook verification and local CLI relay.
- `strave-overlays` — Self-hosted OBS overlays with `@strave/overlay-sdk` and live SSE.
